# dotfiles

## How to setup
- Copy or pull this repo inside new system
- `bash install.sh`
- `source ~/.zshrc`

## zsh
- Alias `hist` for `history`
- Set timezone to Asia/Seoul
- tmux window/panes don't share history
- Blank line after every command
- Simplified username

## git
- `log1 10` shows 10 recent commits
- `cm = commit -m`
- `br = checkout -b`
